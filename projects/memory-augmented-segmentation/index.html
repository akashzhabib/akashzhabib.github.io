Memory-Augmented Segmentation for Maritime & Satellite Imagery

Ahsan Habib Akash

West Virginia University

Ongoing project · 2026
Screenshots Results so far
TL;DRFoundation segmentation models like SAM 3 start from zero on every image. This project is an interactive annotation tool that remembers the operator's corrections and feeds them back into SAM 3 as visual prompts, so the model gets better at your domain the more you use it. The goal: a measured reduction in human annotation time at held quality, reproducible on a public dataset.

What I'm trying to achieve

Labeling maritime and overhead imagery is slow and expensive. Frames are large (LaRS frames are 2208 × 1242) and the objects are tiny: across our trial sample, 66% of objects are smaller than 32 × 32 pixels. Finding an object often takes longer than tracing it.

General click-to-segment assistants help with tracing but forget everything between images. Every correction an annotator makes is thrown away. This tool treats those corrections as the most valuable data in the loop:

  • Corrections are fuel. Each accepted, corrected or hand-drawn mask is stored with its embedding and SAM 3 exemplar tokens, and reused as a prompt on future images.
  • A person accepts every label. The model proposes; the operator decides. The only exception is batch auto-accept above an explicit, stated threshold.
  • Machine time and human time are reported separately, so a faster GPU never reads as a better product.

How it works

The system runs two loops. The fast inner loop serves the operator in real time; the slow outer loop turns their decisions into better future predictions.

Inner loop · seconds
  1. New image arrives
  2. FAISS lookup retrieves trusted examples of each concept
  3. SAM 3 segments with those examples as visual prompts
  4. Candidates are de-duplicated and ranked
  5. Operator accepts, relabels, redraws or rejects
Outer loop · over sessions
  1. Every decision is logged and attributed to the examples used
  2. Corrections enter the concept memory with a trust tier
  3. Examples are ranked by measured help-rate (Wilson bound)
  4. Examples that keep hurting are quarantined, reversibly
  5. Future scans improve without retraining the model

Key components

Memory
Trusted concept store

Human-verified examples are trusted; batch auto-accepts are only provisional. This fixed a real failure where the model's own unverified output was poisoning its memory.

Recall
Two-stage small-object scan

An open-vocabulary detector proposes up to 12 regions; each is cropped, segmented by SAM 3 at native resolution and pasted back.

Precision
Part-of-whole de-duplication

Near-duplicate masks are suppressed within a concept, but nested structure (a window inside a car) is never deleted across concepts.

Effort
Active-learning review queue

Batch results below threshold are ordered by entropy, ambiguity, novelty and boundary distance, grouped by image to avoid context switches.

The tool

The tool is a napari plugin built for expert operators: keyboard-first, one Labels layer per concept, project-scoped stores (current projects: Littoral, car and satellite). The whole annotation path runs from the keyboard: R scan, Shift+R find small objects, Space next candidate, A accept, X reject, E redraw, 1–5 pick a concept, M toggle memory.

What has not been measured yet. Human annotation time has not yet been measured, either by hand or with the tool. Any effort figure is a prediction from published per-action costs and is labeled as one. A counterbalanced timing study (manual LabelMe vs. SAM-assisted vs. memory-augmented) is designed and is next.

What's next

  • Human timing study. Three arms, paired and counterbalanced, on a stratified, seeded LaRS sample with committed manifests so the image selection is checkable. Headline metrics: time-to-quality and cost per 1,000 masks.
  • Reusable effort benchmark. Calibrate per-action cost coefficients once with humans, then predict effort from automatically counted actions on every release.
  • Memory ablations. Measure how much each lever (trust tiers, utility ranking, review ordering) contributes as memory warms up.
  • Web review surface for demonstrations and non-operator reviewers.

Built with SAM 3 (HuggingFace Transformers), FAISS, napari/magicgui and NumPy. Evaluated on LaRS and an internal car-parts set.
